# Heimdalsgata 1A og 1B

Statisk nettside for sameiet, bygget som enkel HTML/CSS og klar for deploy til Vercel.

## Struktur

- `index.html` inneholder sidens innhold og seksjoner.
- `styles.css` inneholder all styling.
- `assets/hero.webp` og `assets/hero.jpg` brukes som hovedbilde.
- `forsidebildejpg.jxl` er originalfilen som ble brukt til webversjonene.

## Lokal bruk

Siden krever ingen build-step. Åpne `index.html` i nettleser, eller bruk en enkel lokal server hvis du ønsker preview med vanlig HTTP.

## Vercel

Prosjektet kan deployes direkte som et statisk nettsted.

Vanlig flyt:

1. Push mappen til GitHub.
2. Importer repoet i Vercel.
3. Legg til `heimdalsgata1ab.no` under prosjektets domenesider i Vercel.

## Neste innholdsrunde

- Oppdatere navn og tekstinnhold
- Legge inn ekte kontaktinformasjon
- Publisere dokumentlenker
- Justere meny og seksjoner ved behov
